# College Network Design Using Cisco Packet Tracer

## Project Overview
This project focuses on designing and simulating a computer network for a college campus using Cisco Packet Tracer. The network is designed to connect different departments and provide structured communication between network devices.

## Objectives
- Design a structured college campus network.
- Establish communication between different departments.
- Configure network devices such as routers and switches.
- Implement VLANs for network segmentation.
- Configure IP addressing and routing.
- Test network connectivity.

## Technologies Used
- Cisco Packet Tracer
- Cisco Routers
- Cisco Switches
- VLAN Configuration
- IP Addressing
- Router-on-a-Stick
- DHCP

## Network Design
The project uses a structured network topology to connect various departments within a college environment.

The design includes:
- Router-based communication
- Switch-based connectivity
- VLAN-based department segmentation
- IP address allocation
- Inter-VLAN routing

## Implementation
The network was designed and configured in Cisco Packet Tracer. Devices were connected, IP addresses were assigned, VLANs were configured, and routing was implemented to enable communication between different network segments.

## Testing
Network connectivity was tested using the ping command to verify communication between connected devices and network segments.

## Project File
The Cisco Packet Tracer simulation file (`.pkt`) is included in this repository.

## How to Run
1. Install Cisco Packet Tracer.
2. Clone or download this repository.
3. Open the `.pkt` project file using Cisco Packet Tracer.
4. Explore the network topology and configurations.

## Learning Outcomes
- Understanding network topology design.
- Practical experience with Cisco Packet Tracer.
- VLAN and IP addressing configuration.
- Understanding inter-VLAN routing.
- Network connectivity testing.
